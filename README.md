# MissingNo

Game Boy emulator written in C

## Compiling and Running

```
make          # normal build
make run      # build + run

make release  # clean + optimised build
make release run  # optimised build + run

make clean    # remove build/ and bin/
```

Use `ROMS` variable as path to the ROM file
